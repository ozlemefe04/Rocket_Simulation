# Rocket_Simulation

A beginner Python project for simulating vertical rocket flight using basic physics and object-oriented programming.

## Features

*   **Object-Oriented Design:** Clean and modular architecture utilizing `Rocket`, `Environment`, and `Simulation` classes.
*   **Dynamic Physics Calculations:** Real-time tracking of variable mass (as fuel burns), atmospheric drag (air resistance), thrust, and net forces.
*   **Performance Metrics:** Analyzes and outputs maximum altitude, peak velocity, maximum acceleration, and total flight duration.

## Installation & Usage

Follow these steps to run the simulation locally:

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd YOUR_REPO_NAME
   ```
3. Run the script:
   ```bash
   python rocket_simulation.py
   ```
